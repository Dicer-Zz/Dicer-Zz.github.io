## About

This is the source repository for **Dicer's Blog**, a personal technical blog by **Zhicheng Wang** (alias: Dicer), a graduate student at [AntNLP@ECNU](https://github.com/AntNLP), East China Normal University.

The blog covers topics including:

- Natural Language Processing and Model Interpretability
- LeetCode contest solutions and algorithm analysis
- Deep learning frameworks (PyTorch, Apple Silicon GPU acceleration)
- Computer science fundamentals
- Personal projects and life notes

## Tech Stack

The blog is built as a **static site** and deployed via GitHub Pages. Key technologies include:

| Category      | Tools & Libraries                                              |
|---------------|----------------------------------------------------------------|
| Framework     | Hexo (static site generator)                                   |
| CSS           | Bulma CSS framework, custom styles                             |
| JavaScript    | Vanilla JS, jQuery, lightGallery, justifiedGallery             |
| Math Rendering| MathJax                                                        |
| Code Highlight| Highlight.js                                                   |
| Search        | Hexo Insight search with content.json                          |
| UI Components | Font Awesome icons, Google Fonts (Ubuntu, Source Code Pro)     |
